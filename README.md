# page-preview

Браузерный веб-компонент предпросмотра HTML-страницы. Получает её название и
первый заголовок h1, выводит безопасный текст и ссылку в открытом Shadow DOM.
Пакет не имеет зависимостей и не загружает код с CDN.

## Установка и использование

Опубликованный пакет: [@samurai9000/page-preview](https://www.npmjs.com/package/@samurai9000/page-preview).
Исходники: [03LK/page-preview](https://github.com/03LK/page-preview).

```sh
npm install @samurai9000/page-preview@1.0.0
```

В приложении со сборщиком или настроенным import map:

```js
import '@samurai9000/page-preview';
```

```html
<page-preview src="/pages/example.html"></page-preview>
```

Обычный браузер не разрешает имена npm-пакетов без сборщика/import map.
Для локального демо используется относительный импорт исходного файла.
Класс также доступен как именованный и default export.

## Интерфейс

- `src`: HTTP(S)-адрес HTML-документа. Относительный путь разрешается по `document.baseURI`.
- `data-status`: `loading`, `ready` или `error` на элементе компонента.
- `shadowRoot.querySelector('[part="link"]')`: настоящая видимая ссылка на разрешённый URL.
- `[part="title"]`: обрезанное по краям название либо `Название отсутствует`.
- `[part="heading"]`: обрезанный по краям текст первого h1 либо `Заголовок отсутствует`.
- `[part="message"]`: состояние загрузки или сообщение об ошибке.

Пробелы внутри текста сохраняются, HTML-сущности декодируются парсером.
Данные выводятся через `textContent`, HTML удалённой страницы не вставляется в карточку.
При смене `src` предыдущий запрос отменяется, устаревший ответ игнорируется.
Удаление отключает обновления; повторное подключение снова загружает страницу.
Экземпляры независимы. До подключения элемента запросы не выполняются.

Внешний сайт должен разрешать чтение через CORS. `mode: 'no-cors'` не применяется,
так как такое обращение не позволяет прочитать HTML. HTTP-ошибка, сетевая ошибка,
пустой или неподдерживаемый URL переводят элемент в `error`.

## Демо и проверки

Из корня проекта:

```sh
python3 -m http.server 8000
```

В Windows при необходимости используйте `python` вместо `python3`.
Откройте `http://localhost:8000/demo/` и `http://localhost:8000/tests/`.
Тесты работают в настоящем браузере без дополнительных библиотек.
Демо нельзя запускать через `file://`.

## Публикация

1. Создайте аккаунт npm и выполните `npm login` самостоятельно.
2. Проверьте имя: `npm whoami`.
3. Убедитесь, что `npm whoami` выводит `samurai9000`.
4. Выполните `npm run check` и `npm pack --dry-run`.
5. Опубликуйте: `npm publish --access public`; выполните запрошенное npm подтверждение.
6. Проверьте: `npm view @samurai9000/page-preview@1.0.0 version`.
7. Загрузите исходники в свой репозиторий и сдайте его ссылку вместе со строкой
   `@samurai9000/page-preview@1.0.0`.

Имя Moodle `spach` не обязательно совпадает с именем пользователя npm.
Повторная публикация той же версии невозможна; для исправлений используйте
`npm version patch`.
